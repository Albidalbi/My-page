# Guide: Preparing This Website as a PDF Portfolio

This document explains how the current portfolio website can be turned into a clean text document with images and then exported as a PDF.

## Goal

The website already contains the material needed for a PDF portfolio:

- project titles
- project descriptions
- technology lists
- collaborator credits
- contact links
- screenshots, GIFs, and artwork

The PDF version should present the same content in a format that is easier to send, print, or attach to applications.

## Recommended Output

Prepare the PDF as a visual document with:

1. A front page with name, role, and contact details.
2. A short profile or introduction.
3. One section per project.
4. One or more images for each project.
5. A final page with links and contact information.

The best result will usually come from building the document in Word, Google Docs, Canva, Figma, or InDesign, then exporting to PDF.

- index.html: header text, skills section, contact section

## 6. Image Selection Guidance

Do not place every available image into the PDF. Select only the images that best support the explanation.

Use these image types:

- gameplay screenshots for showing the player experience
- GIF stills converted to static frames for print-friendly layout
- concept sketches to show process
- editor screenshots only when they explain technical work clearly
- sprite sheets or asset closeups for pixel art projects

For each project, aim for:

- 1 hero image
- 1 supporting image
- optional 1 process image

That is usually enough.

## 8. Writing Style for the PDF

The website descriptions are already usable, but the PDF will read better if the text is slightly edited.

Use this style:

- write in full sentences
- keep paragraphs short
- lead with what the project is and what you contributed
- avoid repeating "this project showcases" in every section
- keep each project to roughly half a page or one full page depending on image count

Good structure for each project description:

1. What the project is.
2. What you worked on.
3. What skills or results it demonstrates.

## 9. Preparing Images for PDF Use

Before inserting images into a document:

1. Pick the clearest still images from the Portfolio folder.
2. If the source is a GIF, capture a clean frame from it.
3. Rename image files clearly if needed.
4. Resize very large images so the document stays manageable.
5. Keep image widths consistent across project sections.

Recommended practical rules:

- use PNG for screenshots and pixel art
- use JPG for large photos or sketches if file size matters
- avoid inserting huge original assets directly if they slow down the document
- keep margins and image spacing consistent

## 10. Building the Document

The simplest workflow is:

1. Copy the website text into a document editor.
2. Rewrite each section for PDF reading rather than web browsing.
3. Insert selected images under the matching project sections.
4. Add headings, page breaks, and consistent typography.
5. Export the finished document as PDF.

Suggested document settings:

- page size: A4 or Letter
- margins: medium
- body font size: 10 to 12 pt
- heading hierarchy: clear and consistent
- image captions: optional, but useful for prototypes and process images
